# Worked example: 2024-05-14 X8.8 flare

This document records the event-specific scientific decisions used by the
tutorial. It is provenance, not a set of defaults for other flares.

## Input and source selection

- Event: 2024-05-14 X8.8 flare; GOES peak 16:48:46 UT.
- Input: calibrated, concatenated `IDB20240514_163948-165948.cal.ms`.
- Solve interval: `2024/05/14/16:47:12~2024/05/14/16:47:20`.
- Reason: first broad microwave maximum, before later narrow spikes.
- Correlation: `XX`.
- Helioprojective center: `(Solar X, Solar Y)=(+902,-293)` arcsec.
- Derived phase center:
  `J2000 0.8975568718764093rad 0.3247543505252678rad`.
- The radial distance is 948.39 arcsec versus an apparent solar radius of
  948.99 arcsec, so the selected source is at the west limb.
- The LMSAL cutout center `(883.2,-268.8)` was retained as provenance but was
  about 26 arcsec farther inward than the JHelioviewer source cursor.

## Calibration and antenna evidence

The observing log reported:

- reference calibration: 2024-05-15 01:56 UT, 80 minutes, EOVSA antennas
  1–7, 9, 11–13;
- phase calibration: 2024-05-15 01:11 UT, 16 minutes, same antennas;
- antenna 7: no VPOL all day;
- antenna 8: lab testing after 21:20 UT; and
- antenna 10: no VPOL all day.

EOVSA labels are 1-based; CASA IDs are 0-based. Preflight confirmed the actual
mapping in this MS. Fully flagged CASA IDs 7, 9, and 13–15 were excluded.
CASA ID 6 was retained below SPW 23 and excluded at SPW 23 and above.

Selections used:

```text
general antennas:       0~6,8,10~12
SPW 23 and above:       0~5,8,10~12
reference antenna:      0
minimum baselines/ant:  3
formal minimum S/N:     0.0 (manual QA required)
```

VPOL outages did not automatically exclude an otherwise usable antenna from
this XX-only solve. Availability was decided from the requested correlation,
preflight flags, and visibility diagnostics.

## SPW and mask decisions

The [illustrated mask-making reference](../examples/2024-05-14-x8.8/mask-making-reference/README.md) shows the pre-mask survey, the poor SPW 1–2 morphology, and the accepted representative masks used to guide this event.

The pre-mask survey showed:

- SPWs 1–2: rejected;
- SPWs 3–31: source identifiable and included;
- SPWs 32–37: weak or ambiguous;
- SPWs 38–49: ignored for this solve.

Mask groups and browser representatives:

| Mask group | Browser SPW |
|---|---:|
| 3–6 | 5 |
| 7–14 | 12 |
| 15–22 | 18 |
| 23–31 | 24 |

Mask-browser parameters:

```text
nmajor=-1
niter=100
cycleniter=25
threshold=0.0
nsigma=0.0
gain=0.05
cyclefactor=1.0
```

One cycle was used to assess each compact source mask. Masks included the
connected bright source plus a small buffer and excluded detached sidelobes.

## Imaging and solving decisions

```text
image size:       512 pixels
cell:             1 arcsec/pixel
flare FOV:        256 x 256 arcsec
Briggs robust:    1.0
UV selection:     >500lambda
round 1:          phase only, 100 model iterations
round 2:          phase only, 50 model iterations
amplitude solve:  not used
```

Round 0 to round 1 produced the primary image improvement. Round 1 to round 2
was stable, so round 2 was accepted as convergence. An amplitude solution was
not justified by the QA and remained optional.

## Limitations that must accompany the result

- The accepted solve interval is only eight seconds.
- Phase-only self-cal does not redefine the absolute flux scale.
- SPWs 3–4 remained less reliable than the stable middle bands.
- The accepted solve ends at SPW 31, about 11.97 GHz. Products above 12 GHz
  are context only and must not be described as self-calibrated.
- The eight-second visibility spectrum is not the observatory's full
  15-minute calibrated flare spectrum.
- Dirty MFS diagnostics contain synthesized-beam stripes and negative bowls;
  use mask-guided per-SPW images for round acceptance.
